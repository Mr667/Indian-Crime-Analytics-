# Indian-Crime-Analytics- 2014
📊 **Power BI Project: Indian Crime Analysis Dashboard | Data Analytics & Visualization**

I'm excited to share one of my recent data analytics projects — an **Indian Crime Analysis Dashboard built using Microsoft Power BI**, using a crime dataset sourced from Kaggle.

The objective of this project was to transform raw crime data into meaningful, interactive visualizations that make it easier to explore crime patterns across Indian states and districts.

🔍 **Key Features of the Dashboard**

🔹 **Executive Overview:** A high-level summary of reported crime figures, helping users understand the overall distribution of crime across states and districts.

🔹 **State-Wise Crime Analysis:** Compare reported crime counts across States and Union Territories to identify areas with higher recorded numbers.

🔹 **District-Level Analysis:** Explore crime figures at the district level and compare districts within different states.

🔹 **Top 10 Districts by Selected Crime:** An interactive visualization that allows users to select a crime category, such as Theft or Murder, and dynamically view the districts with the highest reported counts.

🔹 **Crime Category Comparison:** Analyze different crime categories and compare their reported counts using interactive charts.

🔹 **District Crime Heatmap:** Use conditional formatting to highlight differences in crime counts across districts and categories, making patterns easier to identify.

🔹 **Interactive Crime Explorer:** Explore the data using State, District, and Crime Category slicers, allowing users to filter visualizations and investigate specific areas of interest.

🛠️ **Tools & Technical Skills Applied**

✅ Microsoft Power BI  
✅ Power Query for data cleaning and transformation  
✅ DAX for calculated measures, rankings, and dynamic crime selection  
✅ Data modeling and table relationships  
✅ Interactive slicers and cross-filtering  
✅ Data visualization and dashboard design  
✅ Conditional formatting and Top N analysis  

💡 **Key Learning Outcomes**

This project helped me strengthen my understanding of data modeling, DAX measures, Power Query transformations, and interactive dashboard development. It also reinforced the importance of data quality, correct relationships, and choosing visualizations that communicate insights clearly.

📌 **Important Note:** The dashboard analyzes reported crime counts in the dataset; higher counts do not necessarily indicate higher crime risk without considering population and other relevant factors.

I believe data analytics is not just about creating charts — it is about turning data into information that people can explore, understand, and use to ask better questions.
